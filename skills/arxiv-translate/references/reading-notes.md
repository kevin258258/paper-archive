# Reading notes

Read the original full text, including appendices and relevant bibliography context, before writing the final notes. Record physical PDF page numbers. A bounded provider request is not permission to omit the rest; use multiple batches.

1. `Agent-精简Insight.md`: one judgment, three useful insights, the crucial experimental evidence, limitations and an open question. About 400–800 Chinese characters.
2. `Agent-核心方法.md`: problem setup, objectives/equations, algorithm steps, assumptions, implementation details and a minimal reproduction plan. Distinguish reported settings from suggested settings.
3. `Agent-详细导读.md`: a detailed Chinese reading guide explaining the motivation, method, experiments, ablations, limitations and reading route; usually about 2,000 Chinese characters or longer when warranted.
4. `Agent-关联与Novelty审判.md`: explicit citations, direct methodological relationships and tentative connections, clearly distinguished. Do not invent sources or “first ever” claims. A comparison within one personal library does not establish global novelty.

Preserve meaningful uncertainty. Never fabricate experimental numbers, affiliations, citations or page evidence. Leave the user's human notes and review decisions untouched.
